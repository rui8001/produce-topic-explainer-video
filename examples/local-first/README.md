# 示例：为什么“本地优先”软件重新流行？

这个示例只展示输入简报，不是一条已核验的成片脚本。

- `promise` 把模糊选题变成观众可验证的收获。
- `opening_conflict` 提供开头的现实冲突。
- `evidence_plan` 显式保留尚未完成的来源工作，不能把它直接写成已证实事实。
- `prohibited_claims` 防止把设计原则夸大成绝对安全承诺。
- `visual_roles` 要求人物、证据与模型互相解释，而不是堆装饰画面。
- `publication_authorized: false` 表示制作与公开发布是两次独立授权。

运行 Skill 时，可以把这个 JSON 作为起点，再让它完成来源核验、口播、视觉计划和样片闸门。
