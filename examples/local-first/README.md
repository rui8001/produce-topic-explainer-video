# 示例：选择本地优先软件时，应检查什么？

这是可复现的配音前工作流，包含来源、口播和视觉计划；没有伪装成已完成的视频。原来的“重新流行”缺少趋势证据，因此收敛成可核验的选型问题。

- `promise` 把模糊选题变成观众可验证的收获。
- `opening_conflict` 提供开头的现实冲突。
- `evidence_plan` 关联已检查的第一手来源；来源不能支持的结论另行标明。
- `prohibited_claims` 防止把设计原则夸大成绝对安全承诺。
- `visual_roles` 要求人物、证据与模型互相解释，而不是堆装饰画面。
- `publication_authorized: false` 表示制作与公开发布是两次独立授权。

依次阅读 [简报](brief.json)、[来源台账](source-ledger.json)、[口播稿](script.txt)、[视觉计划](visual-plan.json)、[上屏文字](on-screen-copy.json) 和 [生产状态](production-status.md)。按 [QC 记录](qc.md) 的命令可独立验证产物关联。音频、精确时间轴、样片批准和逐帧 QC 仍需在真实制作时完成。
