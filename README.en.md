# Produce Topic Explainer Video

An independently installable Codex Skill that turns an arbitrary topic into a source-checked vertical explainer video.

It covers topic framing, evidence boundaries, spoken script, continuous narration, audio alignment, a coherent persona/evidence/model visual system, representative sample approval, and frame-level quality control. It is method-first and does not include the maintainer's private productions, brand assets, accounts, or media.

## Install

```bash
git clone https://github.com/rui8001/produce-topic-explainer-video.git \
  ~/.codex/skills/produce-topic-explainer-video
```

Then ask:

```text
$produce-topic-explainer-video Explain why local-first software is returning in a 90-second vertical video.
```

See [SKILL.md](./SKILL.md) for the operating contract and [README.md](./README.md) for the full Chinese guide.
