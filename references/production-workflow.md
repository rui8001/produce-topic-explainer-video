# Topic-explainer production workflow

1. Lock `00-brief.json`: topic, audience, promise, angle, platform, duration, brand overlay, prohibited claims, and authorization.
2. Build a fact sheet and source ledger. Mark missing real evidence rather than generating it.
3. Lock the spoken script and the list of approved on-screen semantic labels.
4. Generate or import one continuous narration. Record the accepted file, duration, hash, voice rights, and loudness review.
5. Align captions from the real audio; require a continuous timeline with no overlap or gap.
6. Build the semantic visual plan using presenter/persona, evidence, and model roles.
7. Acquire only authorized assets. Review identity, provenance, privacy, text, and transparency before keyframe lock.
8. Author the composition in one persistent visual world. Keep video evidence muted and narration on a separate audio track.
9. Render a representative 30 fps sample up to 60 seconds. Run the complete QC matrix.
10. Record explicit sample approval, render the final target, repeat QC, and package only the final video, captions, and final report.

No standard local-production request implies publication, account access, purchases, subscription use, or repeated paid generation.
