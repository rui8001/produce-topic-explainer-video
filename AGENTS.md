# Repository guidance

This repository is one independently installable Codex Skill. Keep `SKILL.md` at the repository root and keep the folder, frontmatter name, examples, UI metadata, and README consistent with `produce-topic-explainer-video`.

Never commit private production media, personal paths, credentials, account data, client information, voice samples, or copyrighted examples. Use synthetic or clearly redistributable examples.

Validate `SKILL.md`, parse YAML and JSON, inspect the tracked-file inventory, and scan for secrets before a release. Preserve automatic invocation unless a maintainer explicitly changes the policy.
