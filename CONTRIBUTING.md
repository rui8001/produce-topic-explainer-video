# Contributing

Issues and pull requests are welcome when they improve the reusable topic-video method without importing private production content.

Before submitting:

1. Keep the Skill independent of one brand, presenter, voice, topic, or video framework.
2. Use redistributable examples and remove personal, account, client, and production data.
3. Keep detailed conditional guidance in `references/` and link it from `SKILL.md`.
4. Run the official Skill validator and inspect all changed Markdown, YAML, and JSON.
5. Explain the production failure or quality gap that the change fixes.

Changes to required artifacts or gates should include migration notes in `CHANGELOG.md`.
