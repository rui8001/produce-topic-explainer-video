# FAQ

## 只给一句选题也能开始吗？

可以。Skill 会先把它转成具体承诺，并指出还需确认的事实、素材和授权；不会要求用户先写完脚本。

## 是否必须出镜或使用虚拟人物？

不必须。`persona` 是帮助观众进入问题的语义角色，可以是真人、抽象指示器、手势、光标或其他一致的引导载体。

## 为什么要求一整段连续配音？

连续音频提供真实节奏和时长。逐句估时再拼接很容易造成字幕漂移、呼吸不自然和镜头节奏碎裂。

## 能直接生成虚构的软件界面来当证据吗？

不能。示意模型可以明确标注为示意；证据窗口必须来自真实、合法且经过隐私检查的内容。

## 它和教学视频 Skill 有什么不同？

本 Skill 以解释、判断和行动为主要成功标准；教学视频 Skill 额外要求学习目标、常见误解与迁移任务。
